# Product

## Register

product

## Users

Mac users who already have an API relay URL, model name, and API key. They want Claude Code or Codex to use that relay without manually editing JSON or TOML files.

## Product Purpose

RelayMate configures one supported coding client at a time through a short guided form. It validates the relay before changing files, preserves the user's original configuration, and restores that configuration on demand.

## Brand Personality

Calm, precise, and compact. The product should feel like a focused macOS system utility whose result is immediately understandable.

## Anti-references

Avoid provider marketplaces, dashboards, sidebars, promotional content, dense advanced settings, decorative cards, and infrastructure terminology. Do not resemble a general AI control center.

## Design Principles

1. Keep the primary task visible without navigation.
2. Explain current state before offering an action.
3. Validate first, then change configuration atomically.
4. Preserve user-owned settings and make restoration obvious.
5. Reveal technical detail only when an error requires it.

## Accessibility & Inclusion

Use native macOS controls, keyboard navigation, VoiceOver labels, system text scaling, sufficient contrast, and reduced-motion behavior inherited from system settings.
